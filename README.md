# RITMOX

Aplicativo de treinos desenvolvido pela Nexon Labs.

## Stack
- FastAPI
- HTML/CSS/JavaScript
- SQLAlchemy
- PostgreSQL em produção / SQLite local
- Render

## Primeira fase
- Dashboard responsivo
- Navegação base
- Musculação
- Corrida
- Evolução
- Perfil
- Estrutura preparada para novas modalidades e futura integração com Strava

## Executar localmente

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Acesse http://localhost:8000
